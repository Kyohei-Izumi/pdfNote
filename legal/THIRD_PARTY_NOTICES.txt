Qt and PySide6 are inside pdfNote.exe as separate libraries (DLLs), packed
together by PyInstaller. To use pdfNote with a modified version of them, as
the GNU LGPL permits:

  1. Get pdfNote's source code, install Python 3.12, and install the packages
     listed in requirements.txt.
  2. Put your modified Qt or PySide6 libraries in place of the ones in the
     installed PySide6 package (or build PySide6 from source against your
     modified Qt).
  3. Either run pdfNote from source ("python app.py"), or build a new
     executable in the source folder with
     "python -m PyInstaller --noconfirm --clean pdfNote.spec".

GNU libiconv is linked into lxml's etree module (lxml/etree.*.pyd), which
PyInstaller packs into pdfNote.exe. To use pdfNote with a modified version of
it, as the GNU LGPL v2.1 permits:

  1. Get pdfNote's source code and the lxml 6.1.3 source code above.
  2. Build lxml from that source with your modified libiconv. On Windows,
     lxml's build takes ready-made libraries from lxml's libxml2-win-binaries
     project (above): put your modified libiconv in that project's libiconv
     folder and run its build.ps1, then build lxml as a static build (lxml's
     setup.py option --static) with the environment variables INCLUDE and
     LIBRARY also naming the include and library folders build.ps1 made.
     Install the result in place of the lxml package that requirements.txt
     installs.
  3. Run pdfNote from source, or build a new executable, as in step 3 above.
