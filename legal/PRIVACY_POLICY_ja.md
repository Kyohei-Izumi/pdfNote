# pdfNote プライバシーポリシー

最終更新日：2026年9月25日

このプライバシーポリシー（以下「本ポリシー」といいます。）は、泉　恭平が Microsoft Store で提供する pdfNote（以下「ストア版」といいます。）及び利用者から当方に送られる連絡に関して、個人情報がどのように取り扱われるかを説明するものです。pdfNote 利用規約で定義された用語は、本ポリシーにおいても同じ意味で用います。

## 概要

この概要は便宜のためのものであり、本ポリシーの本文が優先します。

- ストア版は、利用者の文書、その内容、そのファイル名、及びストア版の使用状況に関する情報を、当方にも第三者にも送信しません。情報がストア版の外に出るのは、印刷やリンクを開く操作など、第6条に定める場合に限られます。
- ストア版には、広告、アナリティクス及びテレメトリーはなく、広告識別子や位置情報も使用しません。
- 利用者の設定及び第4条に定める作業用のファイルは利用者のデバイスに保存され、当方はこれらにアクセスできません。
- 当方が個人情報を受け取るのは利用者が当方に連絡した場合（第8条）に限られ、そのほかには、Microsoft が提供者向けに提供する集計済み又は個人を識別できない形のレポート（第7条）を閲覧するのみです。

## 第3条（ストア版が行わないこと）

ストア版は、次のことを行いません。

- 利用者の文書、その内容又はそのファイル名を、当方又は第三者に送信すること（第6条に定める場合を除きます。）
- 利用者の使用状況に関する情報を収集し、又は送信すること（アナリティクス又はテレメトリー）
- 広告を表示し、又は広告識別子を使用すること
- 位置情報、カメラ、マイク又は連絡先にアクセスすること
- 当方のアカウントの作成を求めること

ストア版はインターネットを通じて個人情報を収集しないため、「Do Not Track」の信号はストア版に影響しません。

## 第4条（利用者のデバイスに保存される情報）

ストア版は、次の情報を利用者のデバイスに保存します。これらは当方に送信されず、当方はこれらにアクセスできません。

| 情報 | 内容 | 削除される時期 |
|---|---|---|
| 設定 | 表示言語、配色、最近開いたファイル（最大10件）のパス、最後に開いたフォルダー、無料試用期間を開始した日時及びストア版がそれを最後に確認した日時、並びにストア版が利用者に表示した利用規約及び本ポリシーの版とその日時 | ストア版をアンインストールしたとき |
| 自動復旧用の複製 | 未保存の変更がある文書の内容、並びにその文書のパス及び表題、複製を作成した日時、及び複製を作成した pdfNote のプロセス番号と起動日時。予期しない終了の後に作業を復元するために保存します。 | 文書を保存し、又は閉じたとき。予期しない終了の後は、次回起動時に復元し、又は破棄したとき |
| エラーの記録 | 予期しないエラーによりストア版が停止したときに記録される技術的な情報。ファイルのパス及び名前が含まれることがあります。 | ストア版をアンインストールしたとき |
| OCR の言語データ | 利用者が OCR の言語データのフォルダーに置いたファイル | 利用者が削除したとき、又はストア版をアンインストールしたとき |
| 一時ファイル | 文書の保存中に保存先のフォルダーに作成されるファイル、及び実行中にプログラムの構成要素を置く一時フォルダー | 保存が完了したとき、及びプログラムが終了したとき |

ストア版では、Windows が、設定、自動復旧用の複製、エラーの記録及び OCR の言語データをアプリのパッケージ専用の場所に保存し、アンインストール時に削除します。利用者は、これらのファイルをいつでも削除することができます。機密性の高い文書を取り扱った後は、自動復旧用の複製を削除することをお勧めします。

1\. 付箋を追加し、又は編集すると、ストア版は、利用者の Windows のユーザー名を付箋の作成者として記録します。保存された文書を受け取った人は、通常、PDF ソフトウェアでこの名前を見ることができます。サニタイズしても、この名前は削除されません。文書を共有する前に確認してください。

3\. 墨消し及びサニタイズの限界については、利用規約第8条第4項に定めるとおりです。

## 第6条（情報がストア版の外に出る場合）

情報がストア版の外に出るのは、次の場合に限られます。(1) のプレミアム購入の確認を除き、いずれも、利用者自身の操作又は Windows の動作によるものです。

(1) **プレミアム購入**：購入は Microsoft Store を通じて、Microsoft 自身の購入画面で行われ、Microsoft が処理します。ストア版は、購入できる商品を表示するため、利用者が確認した購入を開始するため、及びプレミアム購入が有効かどうかを確認するために Windows の Microsoft Store の機能に問い合わせ、この機能が Microsoft と通信することがあります。ストア版が受け取るのは、商品の名称や価格など提供されるアドオンに関する情報、及びアドオンを保有しているかどうかなど購入の状態に関する情報のみです。

(2) **リンク**：文書内のリンクを開くときは、ストア版が利用者に確認したうえで、既定のブラウザーその他のアプリケーションにリンクを渡します。ウェブサイト又はアプリケーションは、それぞれのポリシーに従って情報を受け取ります。

(3) **印刷**：印刷する文書は、Windows の印刷機能及びプリンター ドライバーに渡されます。ネットワーク プリンターや印刷サービスが、これを送信することがあります。

(4) **クリップボード**：コピー又は切り取りをした内容は Windows のクリップボードに置かれ、他のアプリケーションが読み取ることができます。Windows でクリップボードの履歴又は同期が有効になっている場合、Windows がその内容を保持し、又は同期することがあります。

(5) **ストア版の実行中にファイルを開く場合**：ストア版がすでに実行されているときに PDF ファイルを開くと、ファイルのパスが、デバイス内の名前付きパイプを通じて実行中のストア版に渡されます。パイプの名前には、利用者の Windows のユーザー名が含まれます。ネットワークには接続しません。

(6) **Windows その他のサービス**：ファイルのダイアログ、エクスプローラー、Microsoft Store による更新の配信、及び Windows による診断データの収集は Windows の機能であり、Microsoft の条件及びプライバシーに関する声明が適用されます。OneDrive その他のクラウド ストレージ サービスが同期するフォルダーで文書を開き、又は保存した場合は、そのサービスがその条件に従って文書を送信します。

ストア版は、これら以外にインターネットに接続しません。文字認識（OCR）は、利用者のデバイス上で行われます。
