# pdfNote

Mouse to the cat, hands to the keys, passion to the future. pdfNote, the shortcut-oriented PDF editor, lends a hand.

## Support the developer: get pdfNote from the Microsoft Store

pdfNote is made by a young developer working entirely alone. It has no ads and no tracking, so what keeps it going is the people who get it from the Microsoft Store and buy the paid version there. If pdfNote is useful to you, please install it from the Microsoft Store:

https://apps.microsoft.com/detail/9PHFQ0RJ0P6W

The Store edition also gets its updates automatically.
